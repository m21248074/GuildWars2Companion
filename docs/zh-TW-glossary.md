## 排版與語氣

- 使用全形標點(,。:?!)。
- 避免使用「你/您」,改用沒有主詞的句子,例如「確定要變更語言嗎?」。
- 中文與英文、數字之間加一個半形空格,例如「API 金鑰」。

## 已知的用詞不一致

遊戲資料(物品、成就等)是由 API 的簡體中文自動轉成繁體,用詞與上面的詞表不一定相同。
例如資料裡的「專精」多半指 Specialization,而介面的「專精」指 Mastery。目前接受這種不一致,
需要時再針對常見片語加覆寫詞表。
